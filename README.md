# Mon Livret Citoyen 2026 - Version 3

Version native de lecture : pas d’images PDF, pas d’OCR, pas d’audio.

## Inclus
- les 5 parties du Livret du citoyen 2026
- lectures natives en français
- traduction anglaise sous chaque section
- vocabulaire
- progression locale
- exercices sous chaque partie : QCM, vrai/faux, texte à trous, association, classement et réponse courte

## Déploiement
Remplacez dans votre dépôt GitHub :
- index.html
- styles.css
- app.js
- course-data.js
- exercises.js

Les anciens fichiers `page-XXX.jpg` ne sont plus utilisés et peuvent être supprimés.
